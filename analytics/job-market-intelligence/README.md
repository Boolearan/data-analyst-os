# Job Market Intelligence

## About the project

This project explores the Spanish data job market to understand what companies are currently looking for in data professionals.

The goal is to analyse real job postings and answer questions such as:

- Which industries are hiring the most data professionals?
- Which technical skills are most in demand?
- Which skills tend to appear together?
- How do requirements change by role and seniority?
- Which sectors offer the most interesting opportunities for data professionals?

## Project goal

The findings from this analysis will be used to design a second end-to-end data project focused on a relevant and in-demand industry.

## Tech stack

The project will progressively use:

- Python
- SQL
- BigQuery
- Data visualization
- AI / LLMs
